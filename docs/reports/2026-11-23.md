## สิ่งที่ boss ต้องทำ
ตอนนี้ยังไม่มีงานที่ boss ต้องทำก่อน Lead เปิด pull request ของ CR2

เมื่อ Lead แจ้งว่า pull request ของ CR2 พร้อมและ CI เขียวแล้ว:
- [ ] หลัง merge ทดสอบบน production (บนมือถือ) — preview ยังส่งรหัสทางอีเมลไม่ได้ จึงไม่ใช้ preview: แท็บ "ฉัน" → กด "ออกจากระบบ" → ต้องขึ้นหน้าต่าง "ออกจากระบบไหม" ก่อน · กด "ยกเลิก" แล้วยังอยู่ในระบบ
- [ ] (ถ้าเป็นแอดมิน) เปิดหน้าออกโค้ดเชิญ → ฟอร์มต้องขึ้น "ต้องสมัครภายใน" และ "สมัครได้กี่คน" · แชร์โค้ดแล้วข้อความต้องขึ้น "สมัครได้ถึง"
- [ ] ถ้าทั้งหมดผ่าน: กด merge pull request (CI ต้องเขียว) · ถ้าไม่ผ่าน บอก Lead ว่าเห็นอะไร

หมายเหตุ: ถ้า Preview ยังส่งรหัส OTP ไม่ได้ boss ไม่ต้องแก้ตัวแปรเอง (งานของ Lead) — ให้ทดสอบด้วยบัญชีที่ล็อกอินได้อยู่แล้ว (Google) เฉพาะหน้า "ฉัน" และหน้าออกโค้ดเชิญ
