## 1. โครงนำทาง

**แถบล่าง 4 แท็บ:** หน้าหลัก · ประวัติ · ความคืบหน้า · ฉัน (EN: Home · History · Progress · Me)

เหตุผล: งานหลักมีแค่ "เริ่มจด" ซึ่งอยู่บนหน้าหลักในเขตนิ้วโป้งอยู่แล้ว จึงไม่ต้องมีปุ่มกลางแถบ · 4 แท็บทำให้ป้ายภาษาไทยขนาด 14px ("ความคืบหน้า") ไม่ล้นที่จอกว้าง 360px · เทมเพลตอยู่บนหน้าหลัก (ใช้เริ่มเซสชัน) ไม่ต้องเป็นแท็บแยก

| แท็บ | มีอะไร |
|---|---|
| หน้าหลัก | สถานที่ที่จะเล่น (จำล่าสุด) · ปุ่ม **เริ่ม** · ทำซ้ำครั้งก่อน · เทมเพลต 3 อันบนสุด · สัปดาห์นี้ (7 จุด) |
| ประวัติ | รายการเซสชันเรียงตามวัน → รายละเอียดเซสชัน (แก้/ลบเซ็ตย้อนหลัง) |
| ความคืบหน้า | ชิป 3 อัน: สรุป (สัปดาห์/เดือน) · รายท่า (กราฟ) · ร่างกาย (น้ำหนักตัว + จด) |
| ฉัน | R1: โหมด · ภาษา · บัญชี (ความเป็นส่วนตัว · ส่งออก ปิดไว้ · ออกจากระบบ · ลบบัญชี) ตามรูปของ R0 (ข้อ 9–10) · R1.5: แถว "ออกโค้ดเชิญ ›" แถวแรกของส่วนบัญชี **เฉพาะแอดมิน** (ข้อ 11) · รอบหลังเพิ่ม หน่วย เวลาพัก สถานที่ ท่าของฉัน เทมเพลต เครดิต ด้วยรูปเดียวกัน |

- **หน้าจด** เป็นจอเต็ม ไม่มีแถบล่าง · ปุ่ม ‹ มุมซ้ายบนคือ "ย่อ" ไม่ใช่ "ออก" — เซสชันยังเดินต่อ
- ระหว่างมีเซสชันค้าง ทุกแท็บมี **แถบ "กำลังเล่น"** สีดำลอยเหนือแถบล่าง (ชื่อเซสชัน · เวลาที่ผ่านไป · เวลาพักที่เหลือ) แตะแล้วกลับหน้าจด
- ปุ่มหลักของทุกจออยู่ครึ่งล่าง · ช่องค้นหาอยู่บนได้เพราะแตะแล้วแป้นพิมพ์ขึ้นอยู่แล้ว
- สถานะเชื่อมต่อแสดงที่เดียว: แถบบางบนสุดของจอ (ออฟไลน์ / กำลังส่ง / ค้างส่ง N)

## 2. Flow ตาม epic

ตัวเลขในวงเล็บ = จำนวนแตะ นับจากจอแรกของ flow

**E1 บัญชี (US-1.1–1.5)**
1. ยินดีต้อนรับ: ช่องโค้ดเชิญ (เติมให้เองถ้าเปิดจากลิงก์เชิญ `#invite=` — แก้ 2026-11-18 ตาม ADR 0006: query ถูกเก็บใน log ของ Vercel) → **เข้าด้วย Google** (1) → หน้า Google → กลับมา
   - มีบัญชีแล้วไม่ต้องใส่โค้ด · โค้ดตรวจก่อนเด้งไป Google (ผิด = บอกทันที ไม่เสียเวลาไปกลับ)
   - บัญชีใหม่ที่ไม่มีโค้ด → กลับมาจอนี้พร้อมข้อความ "ต้องมีโค้ดเชิญก่อนนะ"
2. ทางรอง: **ใช้อีเมลแทน** → ใส่อีเมล → ส่งรหัส → กรอก OTP 6 หลัก (เติมเองจากอีเมลได้ `autocomplete="one-time-code"`) → ครบ 6 หลักส่งเอง ไม่ต้องกดปุ่ม
3. ครั้งแรกเท่านั้น: ยินยอมความเป็นส่วนตัว → แบบสอบถาม 2 ขั้น → หน้าหลัก (ว่าง)
   - **แบบสอบถามต้องออนไลน์** (คิวออฟไลน์มาใน R3): ขั้น 1 → ขั้น 2 เปลี่ยนในเครื่องเท่านั้น · ส่งครั้งเดียวตอนกด **เริ่มใช้** (ทั้งสองขั้น) · ปุ่มกลับจากขั้น 2 ไปขั้น 1 ค่าไม่หาย
   - ส่งไม่สำเร็จ (เน็ตหลุด / เซิร์ฟเวอร์ผิดพลาด): อยู่จอเดิม **ค่าที่กรอกยังอยู่ในฟอร์มครบ** ข้อความใต้ปุ่ม + ปุ่มเปลี่ยนเป็น **ลองใหม่** · ไม่มีสถานะ "เก็บไว้ส่งทีหลัง" · ค่าอยู่ในหน่วยความจำของหน้าเท่านั้น ไม่เขียนลงเครื่อง — ปิดแอปแล้วต้องกรอกใหม่
   - ระหว่างส่ง: ปุ่มเป็น "กำลังบันทึก…" กดซ้ำไม่ได้
4. เข้าครั้งต่อไป: เปิดแอปเข้าหน้าหลักเลย (session 60–90 วัน) · หมดอายุ → จอยินดีต้อนรับ ไม่มีช่องโค้ด (จำได้ว่าเครื่องนี้เคยเข้า)
5. **แอปที่ติดตั้งบน iPhone ถ้า Google ใช้ไม่ได้** (ADR 0002 ทางถอยข้อ 3 · ใช้เมื่อผลทดสอบเครื่องจริง R1 ไม่ผ่าน): จอยินดีต้อนรับไม่มีปุ่ม Google — โค้ดเชิญ + อีเมล + **ส่งรหัส** (1) อยู่บนจอเดียว → กรอก OTP เหมือนข้อ 2 (ครบ 6 หลักส่งเอง)
   - ใช้เมื่อ iOS/iPadOS **และ** `display-mode: standalone` เท่านั้น — Safari แท็บและ Android ยังมี Google · เปิด/ปิดด้วยค่าตั้งเดียว (flag) ไม่ใช่โค้ดสองชุด
   - ไม่มีข้อความอธิบายว่าทำไมไม่มี Google · ข้อความใต้ช่องอีเมล: "ใช้อีเมลเดียวกับที่เคยเข้า (รวมถึง Gmail ที่เคยใช้กับ Google)"
   - เข้าครั้งต่อไปหลังหมดอายุ: ช่องโค้ดซ่อนเหมือนข้อ 4
   - **ต้องยืนยัน (architect/platform):** คนที่สมัครด้วย Google แล้วเข้าด้วย OTP ที่อีเมลเดียวกัน ได้บัญชีเดิม ไม่ใช่บัญชีใหม่ — ถ้าไม่ได้ จอนี้ต้องออกแบบใหม่

**E2 + E3 เริ่มและจด (US-2.1–2.3, 3.1–3.7)** — เส้นทางหลัก
- เริ่มเปล่า: **เริ่ม** (1) → เลือกท่า: แตะท่าจาก "ล่าสุด" (2) → หน้าจด ค่าเติมจากครั้งก่อน → **✓** (3) = **3 แตะ ~8 วินาที** (เป้า ≤ 15)
- เริ่มจากเทมเพลต/ทำซ้ำ: แตะเทมเพลต (1) → หน้าจดมีทุกท่าพร้อม → **✓** (2)
- ระหว่างมีเซสชันค้าง (มีได้ทีละเซสชัน): ปุ่มเริ่มและชิปสถานที่ถูกแทนด้วยแถบ "กำลังเล่น" · แถวเทมเพลตและทำซ้ำ **จางและแตะไม่ได้** ใต้หัว "เทมเพลต" มีข้อความ "จบเซสชันที่เล่นอยู่ก่อน" · "ทั้งหมด" ยังเปิดดู/แก้เทมเพลตได้
- เซ็ตถัดไปท่าเดิม: แถวถัดไปขึ้นมาให้เองพร้อมค่าเดิม → **✓** (1) ✔ ตรงเป้า PRD
- สถานที่: ชิปเหนือปุ่มเริ่มแสดงที่ใช้ล่าสุด แตะเพื่อเปลี่ยน/เพิ่ม · แก้สถานที่ของเซสชันที่เลือกผิดได้จากเมนู ⋯ ของหน้าจด · ย้ายไปเล่นที่อื่น = จบแล้วเริ่มใหม่
- เลือกท่า: ค้นหา (อังกฤษ/ทับศัพท์ไทย) · ล่าสุด 5 ท่า · ชิปหมวด · ไม่เจอ → "สร้าง '<คำที่พิมพ์>' เป็นท่าของฉัน"
- เพิ่มท่าระหว่างเซสชัน: **+ เพิ่มท่า** (1) → แตะท่า (2)
- ✓ แล้ว: ตัวจับเวลาพักเริ่มเอง (ค่าเริ่ม 90 วิ ตั้งได้ในฉัน) · แถวถัดไปโผล่ · คำนวณสถิติ → ถ้าใหม่ แจ้งเตือนบนสุด 3 วินาที + ดาวที่แถว
- แก้ค่า: แตะตัวเลข → แถวขยายเป็นปุ่ม −/+ + แป้นตัวเลขของเครื่อง · แตะเลขเซ็ต → เมนู: วอร์มอัพ / ลบเซ็ต · แตะ ✓ ที่ติ๊กแล้ว = เอาติ๊กออก (มีปุ่มย้อนกลับใน toast)
- จบ: **จบ** (1) → สรุป → **เสร็จ** (2) · แถวที่ยังไม่ติ๊กถูกทิ้ง (เป็นแค่ค่าแนะนำ) · ไม่มีเซ็ตเลย = ไม่บันทึก ไม่ถาม
- ปิดแอปกลางคัน: เปิดใหม่ภายใน 3 ชม. → กลับหน้าจดเลย · เกิน 3 ชม. → ถาม "ยังเล่นอยู่ไหม" (เล่นต่อ / จบที่เวลาเซ็ตสุดท้าย)
- ออฟไลน์: จดได้ทุกอย่างตามปกติ แถบบนบอก "จดไว้ในเครื่อง N" · กลับมาออนไลน์ส่งเอง → "ส่งครบแล้ว"
- วันที่ของเซสชัน = วันที่ท้องถิ่นตอน **เริ่ม** (เล่นข้ามเที่ยงคืนยังอยู่วันเดิม)

**E4 เทมเพลตและร่างกาย (US-4.1, 4.2)**
- สร้างเทมเพลต: จากสรุปจบเซสชัน "บันทึกเป็นเทมเพลต" (1) → ตั้งชื่อ (ชื่อเซสชันเติมให้) → บันทึก (2) · หรือ ฉัน › เทมเพลต › + ใหม่
- เทมเพลตเก็บ: ชื่อ · ลำดับท่า · จำนวนเซ็ตต่อท่า (ค่าน้ำหนัก/ครั้งเติมจากครั้งล่าสุดของท่านั้นเสมอ ไม่เก็บในเทมเพลต)
- ไม่จำกัดจำนวน · หน้าหลักแสดง 3 อันที่ใช้ล่าสุด + "ทั้งหมด"
- จดน้ำหนักตัว: ความคืบหน้า › ร่างกาย › **+ จดน้ำหนัก** (1) → ปรับค่า (เติมค่าล่าสุดให้) → บันทึก (2) · สัดส่วนอยู่ใน "เพิ่มรายละเอียด" พับไว้

**E5 ความคืบหน้า (US-5.1–5.3)**
- สรุป: ชิป สัปดาห์/เดือน · ‹ › เลื่อนช่วง · วันที่มา · เซสชัน · เวลารวม · ปฏิทินจุด · ท่าที่ทำบ่อย
- รายท่า: เลือกท่า (ล่าสุด/ค้นหา) → ชิปตัววัดตาม track_type → ช่วงเวลา 1 ด. / 3 ด. / 1 ปี / ทั้งหมด → กราฟ + สถิติ + ครั้งที่ผ่านมา · ทางลัด: เมนู ⋯ ของท่าในหน้าจด › "ดูกราฟ"
- ร่างกาย: กราฟน้ำหนักตัว · ค่าล่าสุด · รายการย้อนหลัง (แตะเพื่อแก้/ลบ)
- ส่งออก: ฉัน › ส่งออกข้อมูล (1) → ไฟล์ดาวน์โหลด → toast "ได้ไฟล์แล้ว"

**E6 ติดตั้ง:** Safari บน iOS ที่ยังไม่ได้ติดตั้ง → แผ่นล่างสอน 3 ขั้น บน **จอยินดีต้อนรับก่อนเข้าสู่ระบบ** (ดูข้อ 5.1) · Chrome Android ใช้ปุ่ม "ติดตั้งแอป" ของเบราว์เซอร์ · ปิดแล้วไม่ถามซ้ำ 14 วัน

## 5. ตัดสินแล้ว 2026-11-16

1. **สอนติดตั้งบน iOS ก่อนเข้าสู่ระบบ** — ✓ ตามข้อเสนอ: แผ่นสอนติดตั้งบนจอยินดีต้อนรับ (ข้ามได้ ไม่ถามซ้ำ 14 วัน) เพราะแอปที่ติดตั้งบน iPhone น่าจะไม่ใช้ cookie ร่วมกับ Safari · researcher ยังต้องยืนยันพฤติกรรม cookie (ทดสอบเครื่องจริง R1)
2. **เริ่ม 1 แตะ ไม่มีจอถามสถานที่** — ✓ ตามข้อเสนอ: ใช้สถานที่บนชิปเหนือปุ่มเริ่ม แตะชิปเพื่อเปลี่ยน · เลือกผิดแก้ได้จากเมนู ⋯ ของหน้าจด
3. **แถวถัดไปขึ้นเองพร้อมค่าเดิม** — ✓ ตามข้อเสนอ: ไม่มีปุ่ม "+ เพิ่มเซ็ต" · แถวที่ไม่ติ๊กถูกทิ้งตอนจบ
4. **แบบสอบถามส่วน optional** — ✓ ตามข้อเสนอ: เป้าหมาย (ชิปเลือกหลายอัน) + ประสบการณ์ · ไม่ถามเพศ · อายุเก็บเป็นปีเกิด
5. **หน่วยเป็นชุด** — ✓ ตามข้อเสนอ: สลับครั้งเดียว kg·cm·km ↔ lb·in·mi
6. **distance_duration** — ✗ ไม่ใช้ข้อเสนอเดิม (บังคับทั้งคู่) · boss ตัดสิน: **บังคับเฉพาะเวลา ระยะทางเป็น optional** (หลายคนวิ่งลู่แล้วไม่จดระยะ) · เซ็ตที่ไม่มีระยะไม่นับในสถิติระยะ/เพซ (ADR 0003) · ฟอร์มดูข้อ 3
7. **ตัวจับเวลาพักเตือนได้เฉพาะตอนเปิดแอป** — ✓ ตามข้อเสนอ: รับได้ใน v1 (push เป็น P2) · เวลายังถูกเสมอแม้จอดับ

นอกจากนี้ boss รับแล้ว: การตีความ "ส้มที่เดียวต่อจอ" (ข้อ 6) · รุ่นต่ำสุด iOS/iPadOS 16.4 และ Chrome Android 111 (ข้อ 7) · แบบสอบถาม R1 ต้องออนไลน์ (ข้อ 2 E1 ข้อ 3) · ทางถอยซ่อนปุ่ม Google ในแอปที่ติดตั้งบน iPhone ถ้าทดสอบไม่ผ่าน (ข้อ 2 E1 ข้อ 5)

### 10.2 สิ่งที่แก้จากร่างเดิมให้ตรง API/ADR

- **ลิงก์เชิญ** `/welcome#invite=XXXX-XXXX` (ADR 0006) — ตรวจ wireframes.html และเอกสารนี้แล้วไม่เหลือ `?invite=` · ตัวอย่างโค้ดในภาพเปลี่ยนเป็นตัวอักษรที่ระบบออกจริง (ไม่มี I L O 0 1)
- **โค้ดเชิญผิด = ข้อความเดียว** ("โค้ดนี้ใช้ไม่ได้ · ลองเช็กกับเพื่อนที่ส่งให้อีกที") ทั้งผิด/หมดอายุ/ใช้ครบ/ถูกยกเลิก — ร่างเดิมแยกข้อความ ซึ่งขัด contract เกณฑ์ 3
- **ยินยอม**: ข้อความยินยอมอยู่ในกรอบของตัวเอง มีเรื่องเดียว ไม่รวมกับเงื่อนไขอื่น · เพิ่มหัวข้อ "ถอนความยินยอมได้ทุกเมื่อด้วยการลบบัญชี ถอนแล้วข้อมูลถูกลบหมดและใช้แอปต่อไม่ได้" (PDPA ม.19) · ฉบับ/วันที่ของประกาศมาจาก `PRIVACY_NOTICE_VERSION` · "อายุ" เปลี่ยนเป็น "ปีเกิด" ให้ตรงสิ่งที่เก็บ
- **ไม่ยินยอม** มีจอยืนยัน (ใหม่) → `DELETE /api/me` → ล้างเครื่อง → `/welcome` · ไม่ลบทันทีที่แตะ (กันแตะพลาด)
- **ประกาศความเป็นส่วนตัว** มีกรอบโครงหน้า (ใหม่) 7 หัวข้อครอบเกณฑ์ 8 · เนื้อหาจริง frontend เขียน security-privacy ตรวจ
- **ยินดีต้อนรับออฟไลน์** มีกรอบ (ใหม่) · ไม่มีแถบ "เน็ตหลุด" ในจอนี้ เพราะคำอังกฤษของแถบ ("Offline") ชนกับเทสต์ ADR 0006 ข้อ 6.3
- **OTP**: "เหลือ N ครั้ง" แสดงเฉพาะเมื่อ API บอกจำนวน ไม่งั้นใช้ "รหัสไม่ตรง · ลองอีกที"
- **แบบสอบถาม** ตรงกับ `onboardingSchema`: บังคับ น้ำหนัก ส่วนสูง ปีเกิด ชื่อสถานที่ (1–60 ตัว) · ไม่บังคับ เป้าหมาย 0–4 (`stronger fitter lose_weight show_up`) ประสบการณ์ 0–1 (`new some regular`) · ชิปสถานที่เป็นทางลัดเติมชื่อ ไม่ถูกเก็บ · ช่วงค่าใช้ `ONBOARDING_LIMITS` ตัวเดียวกับเซิร์ฟเวอร์ (20–500 kg · 50–280 cm · ปี 1920–ปีปัจจุบัน)
- **หน่วยเป็นชุด**: ชิป "kg · cm" = kg + cm + km · "lb · in" = lb + in + mi · สลับแล้วแปลงค่าที่กรอกไว้ ไม่ล้าง · ส่วนสูงแบบ lb·in เป็นนิ้วล้วน

- ไม่มีในแถบล่าง

### 11.3 ฟอร์มออกโค้ด (D3)

- ข้อผิดพลาดของการออกโค้ดอยู่ที่เดียว: ข้อความ `--warn` เหนือปุ่ม · ค่าที่กรอกไม่หาย (จอ 53)

### 11.4 กรอบ "แสดงครั้งเดียว" และการแชร์ (D5)

- แทนที่ฟอร์มในที่เดิม · focus ย้ายไปหัวกรอบ (`role="status"` อ่านออกเสียง) · กรอบวาดมือเป็นสิ่งเดียวที่เด่นในจอ (DESIGN ข้อ 7)
- ในกรอบ: หัว "โค้ดแสดงครั้งเดียว" · คำเตือน "ออกจากหน้านี้แล้วจะดูโค้ดนี้อีกไม่ได้ · แชร์หรือคัดลอกไว้ก่อนนะ" · **โค้ด 36px** ตัวกว้างเท่ากัน (แตะค้างเลือกทั้งก้อน) · ลิงก์บรรทัดเดียวตัดด้วย … · สรุป "ป้าย · N คน · ถึง <วันเวลา>"
- ใต้กรอบ (มี `navigator.share`): **แชร์ลิงก์** (ปุ่มหลัก) · คัดลอกลิงก์ | คัดลอกโค้ด (ปุ่มรองคู่) · ลิงก์ "ออกอีกอัน"
- ไม่มี `navigator.share` (ตรวจด้วย feature detection): ปุ่มหลักเป็น **คัดลอกข้อความเชิญ** (ข้อความ D5 ทั้งข้อความ) · ปุ่มรองคู่เหมือนเดิม
- ปุ่มชื่อเดียวกันทำอย่างเดียวกันทุกโหมด: คัดลอกลิงก์ = ลิงก์ล้วน · คัดลอกโค้ด = `XXXX-XXXX` ล้วน · คัดลอกข้อความเชิญ = ข้อความ D5
- แชร์: `navigator.share({ text, url })` จากการแตะเท่านั้น · `AbortError` (ผู้ใช้ยกเลิก) = ไม่มีอะไรเกิดขึ้น · reject แบบอื่น = คัดลอกข้อความเชิญแทน + toast "คัดลอกข้อความแล้ว"
- ลิงก์ = `location.origin + "/welcome#invite=" + code` · โค้ดอยู่ในหน่วยความจำของหน้าเท่านั้น · ไม่มีป้ายหรืออีเมลในข้อความแชร์
- **ออกอีกอัน** = กลับเป็นฟอร์มเปล่า (ค่าเริ่ม 3 วัน / 1 คน) ไม่ถามยืนยัน — โค้ดเดิมยังใช้ได้และอยู่ในรายการ เพิกถอนได้ถ้าออกผิด
- แถวของโค้ดใหม่ขึ้นบนสุดของรายการทันที (ไม่ต้องโหลดรายการใหม่) พื้น `--paper-2` จางหายใน 2 วินาที · `prefers-reduced-motion` = ไม่มีพื้น

**วันเวลา** (กรอบ รายการ และข้อความแชร์): เวลาเครื่อง · `Intl.DateTimeFormat` ตามภาษาของแอป · วัน + เดือนย่อ + ชั่วโมง:นาที 24 ชม. (`hourCycle: "h23"`) · ปีแสดงเฉพาะเมื่อไม่ใช่ปีปัจจุบัน · ภาษาไทยใช้ปี ค.ศ. (`th-TH-u-ca-gregory` — ค่าเริ่มของ `th` คือ พ.ศ.) ให้ตรงกับ "ฉบับ 18 พ.ย. 2026" ที่มีอยู่ · ตัวอย่าง TH `23 พ.ย. 14:05` · EN ลำดับตาม `Intl` ของ `en` (ไม่บังคับรูป)

### 11.5 รายการและสถานะ

- หัวส่วน "โค้ดที่ออกแล้ว" ใต้ฟอร์ม คั่นด้วยเส้นวาดมือ · ใหม่สุดก่อน (ตาม API ≤ 200 แถว) · ไม่มีตัวกรอง
- แถว (สูง ≥ 72px): **ป้าย** (บรรทัดเดียว ตัดด้วย …) · **สถานะ = ไอคอน + คำ** · "ใช้ไป x/y · ถึง <วันเวลา>" · ปุ่ม **เพิกถอน** ชิดขวา (≥ 44px) เฉพาะสถานะ "ใช้ได้"

| `status` | ไอคอน | TH | EN | สีตัวหนังสือ |
|---|---|---|---|---|
| `active` | วงกลมมีจุด | ใช้ได้ | Active | `--ink` · มีปุ่มเพิกถอน |
| `exhausted` | ✓ | ใช้ครบแล้ว | Used up | `--ink-3` |
| `expired` | นาฬิกา | หมดอายุ | Expired | `--ink-3` |
| `revoked` | ✕ | เพิกถอนแล้ว | Revoked | `--ink-3` |

- คำสถานะอยู่เสมอ สีจางเป็นตัวเสริม (ไม่สื่อด้วยสีอย่างเดียว) · ไม่ใช้ `--warn` กับสถานะใด (ไม่ใช่ข้อผิดพลาด)
- ไม่แสดงว่าใครใช้โค้ด (D4) · ไม่มีโค้ดในรายการ (API ไม่ส่ง)

### 11.6 เพิกถอน

แตะ **เพิกถอน** → แผ่นล่าง (จอ 52): หัว `เพิกถอน "<ป้าย>" ไหม` · "ลิงก์และโค้ดนี้จะใช้สมัครไม่ได้อีก · เพื่อนที่สมัครไปแล้วยังใช้แอปได้ตามปกติ" · "ย้อนกลับไม่ได้ · ถ้าต้องการ ออกโค้ดใหม่ได้เสมอ" · ปุ่มเส้น `--warn` **เพิกถอน** · ลิงก์ ยกเลิก

| ผล | สิ่งที่เห็น |
|---|---|
| กำลังส่ง | "กำลังเพิกถอน…" กดซ้ำไม่ได้ |
| `revoked` | แผ่นปิด · แถวเป็น ✕ เพิกถอนแล้ว · toast "เพิกถอนแล้ว" · focus กลับไปที่แถว |
| `unchanged` | แผ่นปิด · โหลดรายการใหม่ · toast "โค้ดนี้ใช้ไม่ได้อยู่แล้ว" |
| ล้มเหลว / เน็ตหลุด | แผ่นยังเปิด · ข้อความ `--warn` เหนือปุ่ม "เพิกถอนไม่ได้ · ลองอีกที" · ปุ่มเป็น "ลองใหม่" |
| 404 | `location.reload()` (เหมือน API แอดมินทุกตัว) |

ยกเลิก / แตะพื้นมืด / Esc = ปิด · คีย์บอร์ด: focus เริ่มที่ "ยกเลิก" (กัน Enter แล้วเพิกถอนเลย) และถูกขังในแผ่น

### 11.10 เรื่องที่ทีมต้องตรวจ (ไม่ต้องให้ boss ตัดสิน)

- **researcher**: ถ้า Google sign-in ใช้ไม่ได้ในเบราว์เซอร์ของ LINE ข้อความแชร์ D5 อาจต้องเพิ่มประโยค "เปิดใน Safari/Chrome" — ux-brand แก้ข้อความเมื่อได้ผล
