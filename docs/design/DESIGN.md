## 1. ความรู้สึกโดยรวม

**แอปเรียบจริงจัง ที่มีแมววาดมือมาป่วน** — ขาวโล่ง ตัวหนังสือเรียบแบบมืออาชีพ ส่วนภาพ เส้น และกรอบเป็นวาดมือ แมวส้มอ้วนหน้านิ่ง ตลกแบบไม่พยายาม

| ใช่ | ไม่ใช่ |
|---|---|
| ขาวโล่ง ที่ว่างเยอะ | การ์ดซ้อนเงา gradient glassmorphism |
| เส้นดำวาดมือ สั่น ไม่เป๊ะ | ไอคอนเวกเตอร์คมกริบ เส้นบางเท่ากันหมด |
| สีเดียวที่เด่นคือส้มของแมว | หลายสีสด สีนีออนแบบแอปฟิตเนส |
| ตลกหน้านิ่ง อบอุ่น ไม่กดดัน | เสียงโค้ชดุ "NO PAIN NO GAIN" ภาพกล้ามใหญ่ |
| ตัวพิมพ์เล็ก ข้อความสั้น | ตัวพิมพ์ใหญ่ทั้งหมด เครื่องหมายตกใจเยอะ |

## 2. สิ่งที่แกะได้จากภาพอ้างอิง

**จากเว็บต้นแบบ (โครงหน้า + ตัวหนังสือ)**
- พื้นขาวล้วน เนื้อหาน้อยต่อหนึ่งจอ ที่ว่างคือองค์ประกอบหลัก
- ฟอนต์ 2 แบบ: **ลายมือเด็ก** สำหรับหัวข้อ (ตัวพิมพ์เล็กทั้งหมด ช่องไฟกว้าง ขนาดตัวอักษรไม่เท่ากันเล็กน้อย) + **sans บางเรียบ** สำหรับเนื้อความ
- ภาพประกอบเป็นเส้นดำล้วน ไม่ลงสี ความหนาเส้นเท่ากันแบบปากกาเมจิก ปลายมน
- กรอบรูปวาดมือ (มุมไม่ฉาก เส้นเกินมุม) · เส้นคั่น/เส้นเชื่อมวาดมือลากยาว · ดาว/ประกายเล็กๆ เป็นของตกแต่ง
- สีตัวหนังสือเป็นเทาเข้ม ไม่ใช่ดำสนิท (#171717, #444, #767676)
- ฟอนต์ของเว็บนั้นเป็นฟอนต์เฉพาะของแบรนด์ **ใช้ไม่ได้** → เลือกฟอนต์ฟรีที่ให้อารมณ์ใกล้กัน (ข้อ 4)

**จากภาพแมว (ตัวละคร + การลงสี)**
- เส้นขอบดำหนา วาดด้วยปากกาหัวใหญ่ ความหนาไม่สม่ำเสมอ เส้นไม่ปิดสนิทบ้าง
- ลงสีเรียบแบบสีน้ำ/มาร์กเกอร์ **สีไม่เต็มเส้น ล้นบ้าง ขาดบ้าง**
- ตัวแมวเป็นก้อน: ตัวสี่เหลี่ยมมน/ถัง หัวกับตัวเป็นชิ้นเดียว ขาสั้นเป็นตอ หูสามเหลี่ยมเล็ก
- หน้าเล็กอยู่กลางก้อนใหญ่: ตาเป็นจุดหรือขีด จมูกสามเหลี่ยมชมพู ปากและแก้มขาวพอง
- อารมณ์: หน้านิ่ง หลับตาพริ้ม ภูมิใจเกินเหตุ — ไม่ยิ้มกว้าง ไม่ตาโตแบบการ์ตูนน่ารักทั่วไป
- ส้มสด + ขาว + ชมพูหู เป็นชุดสีเกือบทั้งหมด

## 3. สี

ใช้ CSS variables · ทุกเส้น/ไอคอนใช้ `currentColor` เพื่อให้สลับโหมดได้เอง

| Token | Light | Dark | ใช้กับ |
|---|---|---|---|
| `--paper` | `#FFFFFF` | `#161514` | พื้นหลัง |
| `--paper-2` | `#F6F4F0` | `#211F1D` | พื้นรอง (แถบ, ช่องกรอก) |
| `--ink` | `#171717` | `#F2EFEA` | เส้นวาด, หัวข้อ, ตัวเลขหลัก |
| `--ink-2` | `#444444` | `#C9C5BE` | เนื้อความ |
| `--ink-3` | `#767676` | `#8F8B84` | คำอธิบายรอง, placeholder |
| `--accent` | `#F9A03A` | `#F9A03A` | จุดเน้นเดียวของหน้า (PR, ปุ่มหลักตอนกด, เซ็ตที่ติ๊กแล้ว, ความคืบหน้า) |
| `--cat` | `#F9A03A` | ไม่ลงสี (= `--paper`) | ตัวแมว |
| `--cat-ear` | `#F4A19B` | ไม่ลงสี | หู จมูก |
| `--cat-white` | `#FFFFFF` | ไม่ลงสี | ท้อง ปาก |
| `--warn` | `#C0392B` | `#E8766A` | ลบ/ข้อผิดพลาดเท่านั้น |

กติกา
- **ส้มมีได้ที่เดียวต่อจอ** (นอกจากตัวแมว) — ถ้าทุกอย่างส้ม ก็ไม่มีอะไรเด่น
- ข้อความบนพื้นส้มใช้ `--ink` (ดำ) ไม่ใช้ขาว — ขาวบนส้มคอนทราสต์ไม่ผ่าน
- ห้ามสื่อความหมายด้วยสีอย่างเดียว (PR = ส้ม + ไอคอนดาว)
- โหมดมืดเป็น "กระดานดำ": เส้นกลายเป็นขาวนวล และ **แมวเป็นเส้นล้วน ไม่ลงสี** (boss ตัดสิน: ส้มบนพื้นมืดไม่สวย) — ส้มเหลือเฉพาะจุดเน้นของ UI

## 4. ตัวหนังสือ

**ฟอนต์เดียวทั้งแอป แบบเรียบจริงจัง ไม่ใช้ฟอนต์ลายมือ** (boss ตัดสิน: Mali/Itim ดูเล่นเกินไป) — ความเป็นวาดมืออยู่ที่ภาพ เส้น และกรอบเท่านั้น

| ตัวเลือก (Google Fonts, มีไทย+ละติน) | ลักษณะ |
|---|---|
| **Noto Sans Thai** (boss เลือก) | มีหัว ตัวสูงโปร่ง ไม่ดูอ้วน อ่านง่ายที่สุดในขนาดเล็ก |
| Prompt (ไม่เลือก) | กลม เรียบ ทันสมัย ไม่มีหัว |
| IBM Plex Sans Thai (ไม่เลือก) | คม เป็นทางการ ไม่มีหัว |

- ฟอนต์ SF ของ Apple นำมาฝังในเว็บไม่ได้ตามเงื่อนไขใบอนุญาต — ถ้าอยากได้หน้าตาแบบ Apple บนเครื่อง Apple ให้ใช้ฟอนต์ของระบบ (`system-ui`) ซึ่งไม่ต้องฝังไฟล์

**คำเด่นลายมือ: Gaegu Light (300)** — boss เลือก · Google Fonts ฝังในเว็บได้
- ใช้กับ **คำสั้นภาษาอังกฤษเท่านั้น** ที่อยากให้เด่น: ชื่อแอป, หัวหน้าจอ, คำฉลอง ("new record", "rest day")
- ตัวพิมพ์เล็กทั้งหมด · `letter-spacing: 0.08–0.12em` · ขนาด ≥ 20px (เส้นบาง เล็กกว่านี้อ่านยาก)
- ห้ามใช้กับ: ภาษาไทย, เนื้อความ, ปุ่ม, ช่องกรอก, ตัวเลข, ข้อความ error
- ข้อความที่เป็นลายมือต้องมีคู่ภาษาไทยด้วย Noto Sans Thai เสมอเมื่อเป็นข้อมูลสำคัญ (ลายมือเป็นของตกแต่ง ไม่ใช่ที่เดียวที่บอกความหมาย)

- น้ำหนัก: 300 เนื้อความ · 400 ป้าย/ปุ่มรอง · 500 หัวข้อ ปุ่มหลัก และตัวเลข
- ตัวเลขในหน้า log: น้ำหนัก 500 + `font-variant-numeric: tabular-nums` (ตัวเลขไม่เต้นเวลา timer เดิน)
- ภาษาไทย: `line-height ≥ 1.6` สำหรับเนื้อความ, `≥ 1.4` สำหรับหัวข้อ (สระบน-ล่างไม่ชนกัน)
- โหลดฟอนต์เอง (self-host ผ่าน `next/font`) ไม่เรียกจาก CDN ตอนใช้งาน — ต้องทำงานออฟไลน์ได้

ขนาด (มือถือ)

| ระดับ | ขนาด | ฟอนต์ |
|---|---|---|
| หัวข้อหน้า | 24–30px | 500 |
| หัวข้อส่วน | 18–20px | 500 |
| ตัวเลขใหญ่ (น้ำหนัก×ครั้ง, timer) | 28–48px | 500 |
| เนื้อความ | 16px | 300/400 |
| คำอธิบายรอง | 14px | 300/400 |

ขั้นต่ำ 14px · ช่องกรอกทุกช่อง ≥ 16px (กัน iOS ซูมเอง)

## 5. ตัวละครแมว (ออกแบบใหม่ ไม่ลอกจากภาพอ้างอิง)

**แมวส้มอ้วน หน้านิ่ง ตัวเป็นก้อน** — ชื่อเรียกชั่วคราว "อ้วน" (boss ตั้งชื่อจริงได้)

สัดส่วน
- ตัว = ก้อนเดียว ทรงถังมน กว้างพอๆ กับสูง · ไม่มีคอ · ขา 4 ตอสั้น · หางสั้นหนา
- หูสามเหลี่ยมเล็ก ห่างกัน ด้านในชมพู
- หน้าเล็ก กินพื้นที่ไม่เกิน 1/3 ของก้อน อยู่ค่อนไปด้านบน
- ตา = ขีดโค้งหรือจุดดำ · จมูกสามเหลี่ยมคว่ำสีชมพู · ปากเป็น "ω" บนแก้มขาวพอง · หนวดข้างละ 2–3 เส้น
- ท้อง/ปลายเท้าขาว

บุคลิก: ขี้เกียจแต่มา · ภูมิใจกับความสำเร็จเล็กๆ เกินเหตุ · ไม่เคยดุผู้ใช้ · ไม่พูดเรื่องรูปร่างในเชิงลบ

**แมวไม่ผอมลงตามน้ำหนักผู้ใช้** — ชื่อแอปคือมุก ไม่ใช่ตัวชี้วัด แมวอ้วนเท่าเดิมเสมอ สิ่งที่เปลี่ยนคือท่าทางและอารมณ์ (กันการทำให้ผู้ใช้รู้สึกแย่กับตัวเลขน้ำหนัก)

## 6. ลายเส้นและการลงสี

เส้น
- สีเดียว `currentColor` · ปลายมนและรอยต่อมน (`stroke-linecap/linejoin: round`)
- หนา ~3px ที่ภาพขนาด 120px (ราว 2.5% ของด้านกว้าง) · ภาพใหญ่เส้นหนาตามสัดส่วน ไม่ใช่เส้นบางลง
- **วาดให้สั่นจริงใน path** (จุดควบคุมไม่สมมาตร เส้นตรงไม่ตรง วงกลมไม่กลม) ไม่พึ่ง filter อย่างเดียว
- ปล่อยให้เส้นไม่ปิดสนิทได้บ้าง, เส้นเกินมุมได้เล็กน้อย
- ไม่มีเงา ไม่มี gradient ไม่มีเส้นซ้อนหลายชั้น

การลงสี
- สีเรียบ ไม่ไล่เฉด · **วาด shape สีแยกจากเส้นขอบ แล้วเยื้อง 1–3px** ให้สีล้นบ้างขาดบ้างเหมือนระบายมือ
- ลงสีเฉพาะตัวแมว (ส้ม/ชมพู/ขาว) — ของประกอบฉาก (ดัมเบลล์ ตาชั่ง นาฬิกา) เป็นเส้นดำล้วน ไม่ลงสี
- ไอคอนเมนู/ปุ่มเป็นเส้นล้วนเสมอ

ของตกแต่ง (ใช้น้อย)
- ประกาย 4 แฉก และดาววาดมือ — เฉพาะตอนฉลอง (PR, จบเซสชัน)
- ลูกศรโค้งวาดมือ — onboarding และ empty state
- เส้นคั่นวาดมือลากยาวแทน `<hr>`

| ปุ่ม ✓ ติ๊กเซ็ต | วงกลมวาดมือ ≥ 56px · ติ๊กแล้วมีเครื่องหมายถูกวาดมือ + พื้นส้ม |
| ปุ่มรอง | ตัวหนังสือ + ขีดเส้นใต้วาดมือ ไม่มีกรอบ |
| การ์ด/กลุ่มข้อมูล | **ไม่มีกล่องเงา** — แยกด้วยที่ว่างและเส้นคั่นวาดมือ กรอบวาดมือใช้เฉพาะสิ่งที่ต้องเด่น |
| ช่องกรอก | เส้นใต้วาดมือเส้นเดียว (ไม่ใช่กล่อง) · ตัวเลขใหญ่ · ปุ่ม +/− วงกลมวาดมือสองข้าง |
| ชิป (สถานที่, หมวดท่า) | วงรีวาดมือ · ที่เลือกอยู่ = พื้นดำตัวหนังสือขาว |
| แถบนำทางล่าง | ไอคอนเส้นวาดมือ 4–5 อัน + ป้ายชื่อ 14px · อันที่เลือก = มีขีดเส้นใต้วาดมือ |
| กราฟ | เส้นกราฟเป็นเส้นวาดมือสีดำ · จุดล่าสุด/PR เป็นจุดส้ม · แกนเป็นเส้นบางสีเทา · ตัวเลขแกนใช้ฟอนต์หลัก |
| ความคืบหน้า | เส้นวาดมือลากยาว มีแมวเดินอยู่บนเส้น (แทน progress bar) |
| Empty state | ภาพแมว + ประโยคเดียว + ปุ่มเดียว |
| แจ้งเตือน/toast | แถบขาวกรอบวาดมือ ไม่มีสีพื้น ยกเว้น error ใช้เส้น `--warn` |

เลย์เอาต์
- mobile-first กว้างสูงสุดของเนื้อหา 480px จัดกลาง · ขอบซ้ายขวา 20px
- ระยะห่างฐาน 4px: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 · ระหว่างส่วน ≥ 32px (ที่ว่างเยอะคือจุดเด่นของแนวนี้)
- หนึ่งจอมีจุดสนใจเดียว · ปุ่มหลักอยู่ครึ่งล่างของจอ กดถึงด้วยนิ้วโป้ง
- **หน้า log คือข้อยกเว้นของ "โล่ง"**: ข้อมูลต้องแน่นพอให้เห็นทุกเซ็ตของท่าโดยไม่ต้องเลื่อน — ลดของตกแต่งให้เหลือศูนย์ เก็บความเป็นวาดมือไว้ที่เส้นและปุ่มเท่านั้น

## 8. การเคลื่อนไหว

- น้อยและสั้น (150–250ms) · เส้นวาดตัวเอง (stroke-dashoffset) ตอนภาพปรากฏครั้งแรก
- **แมวดุ๊กดิ๊ก** (boss ขอ: ใช้ได้หลายจุดบนเว็บ): สลับ 3 เฟรม รอบละ 0.6 วินาที — เส้นสั่นเปลี่ยนทุกเฟรม + ตัวขยับเล็กน้อยรอบจุดกลางล่าง · มีให้ทุกท่าเป็น sprite ใน `assets/stickers/sprites/` (วิธีใช้อยู่ใน README ของโฟลเดอร์นั้น) · ในแอปจริงใช้ SVG inline + CSS แบบใน `samples.html` จะคมกว่าและเปลี่ยนสีตามโหมดได้
- ดุ๊กดิ๊กใช้กับภาพแมวเท่านั้น ไม่ใช้กับปุ่มหรือ UI ที่ต้องกด · ในหน้าจดให้นิ่ง ยกเว้นตอนฉลอง
- PR: แมวชูขา + ประกายเด้ง 1 ครั้ง แล้วหยุด
- เคารพ `prefers-reduced-motion` — ปิดทั้งหมด เหลือแค่การเปลี่ยนสถานะ

## 9. น้ำเสียงข้อความ

- สั้น ตัวพิมพ์เล็ก เป็นกันเอง พูดแบบเพื่อน ไม่ใช่โค้ช · ใช้ "เรา/เธอ" หรือไม่ใช้สรรพนามเลย
- ชมการ "มา" มากกว่าชมตัวเลข: "มาแล้ว เก่ง" ดีกว่า "เผาผลาญไป 300 แคล!"
- ไม่ตำหนิเมื่อขาดหาย ไม่ใช้คำว่า "ล้มเหลว" "พลาดเป้า" · น้ำหนักขึ้น = แสดงตัวเลขเฉยๆ ไม่มีสีแดง ไม่มีคำตัดสิน
- ตัวอย่าง: empty state "ยังไม่มีอะไรเลย · แมวก็ยังไม่ได้ขยับ" · PR "สถิติใหม่ · แมวภูมิใจ (นิดหน่อย)" · ออฟไลน์ "เน็ตหลุด · จดไว้ให้ก่อน เดี๋ยวส่งให้"

## 10. การเข้าถึง (ผูกกับเกต A11y ใน PROCESS.md)

- คอนทราสต์ข้อความ ≥ 4.5:1 ทั้งสองโหมด (`--ink-3` ใช้กับข้อความ ≥ 14px เท่านั้น)
- พื้นที่แตะ ≥ 44px ทุกปุ่ม · ปุ่มในหน้า log ≥ 48px
- ภาพแมวที่เป็นของตกแต่ง `aria-hidden` · ภาพที่สื่อความหมายมี `alt`
- กรอบ focus มองเห็นชัด (เส้นวาดมือหนา 2 ชั้น) ไม่ลบ outline ทิ้ง

## 11. แนวทางทำจริง (สำหรับ UX / Front-end)

- ภาพทุกภาพเป็น **SVG inline เป็น React component** ใน `src/components/doodle/**` · เส้นใช้ `currentColor` · สีแมวใช้ CSS variables → dark mode ได้เอง
- กรอบ/เส้นคั่น/ขีดเส้นใต้วาดมือ: ทำเป็น SVG path สำเร็จรูป 3–4 แบบแล้วสุ่มใช้ (ไม่ให้ซ้ำกันทั้งจอ) · ยืดด้วย `preserveAspectRatio="none"` + `vector-effect: non-scaling-stroke` · rough.js เป็นทางเลือกถ้าต้องสร้างกรอบตามขนาดจริง
- ไม่ใช้รูป raster สำหรับ UI · ไอคอนแอป/splash ส่งออกเป็น PNG จาก SVG ต้นฉบับ
- ตั้ง token ทั้งหมดใน Tailwind theme ชุดเดียว ห้ามใส่ค่าสี/ขนาดตรงๆ ใน component
