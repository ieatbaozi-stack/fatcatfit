# DESIGN.md — แมวอ้วนจะผอม (Fat Cat Fit)

> ร่างแรก 2026-11-15 · สถานะเดิม: อนุมัติ 2026-11-16 (v0.1.0–v0.5.0)
> **อัปเดตครั้งใหญ่ 2026-11-25 (CR4 · Studio Minimal — boss อนุมัติแล้ว):** ยกเลิกกรอบเส้นหนา 2.5px, มุมเบี้ยว (`rounded-hand`), กรอบสี่เหลี่ยมสไตล์ดินสอ, และเส้นยึกยือ (`wavy` / `Squiggle`) ออกจากองค์ประกอบ UI ทั้งหมดตามฟีดแบ็ก user tester — เปลี่ยนเป็น UI สมัยใหม่คลีนเรียบแบบ **Studio Minimal** ที่แยกชั้นพื้นผิวชัดเจนในโหมดมืด, ปุ่มกดชัดเจน, และเพิ่มจุดเด้ง 3 จุดตอนโหลด โดยยังคง **ตัวละครแมวอ้วนวาดมือ 36 ท่า**, **สีส้ม `#F9A03A`**, และ **ฟอนต์ `Noto Sans Thai`** เป็นตัวตนหลักของแอป
> กติกา: ทำแนวทางของตัวเอง ไม่คัดลอกโลโก้ ภาพ ฟอนต์ หรือข้อความของแบรนด์อื่น

## 1. ความรู้สึกโดยรวม

**เครื่องมือจดออกกำลังกายที่เรียบ คม นิ่ง แบบมืออาชีพ ที่มีแมวส้มอ้วนวาดมือเป็นตัวละครหลัก** — โครงหน้า ปุ่ม การ์ด ช่องกรอก และแถบนำทางสะอาดใช้งานง่ายทันทีทั้งกลางแจ้งและในโหมดมืด ความขี้เล่นและลายเส้นวาดมืออยู่ที่ **ตัวละครแมว `<Cat>`** และจังหวะ micro-feedback เล็กๆ (จุดเด้ง 3 จุดตอนโหลด, ติ๊ก ✓, ฉลอง PR) เท่านั้น ไม่เอามาทำให้ปุ่มหรือกรอบดูอ่านยาก

| ใช่ | ไม่ใช่ |
|---|---|
| พื้นผิวสะอาดแยกชั้นชัดเจนทั้ง Light และ Dark | เส้นขอบหนา 2.5px มุมเบี้ยวรอบทุกปุ่มทุกกล่อง |
| ปุ่มหลักทึบคมชัด · ปุ่มรองพื้นรอง (Tonal) ดูออกทันทีว่ากดได้ | เส้นยึกยือ (`wavy` / `Squiggle`) ใช้แทนปุ่มหรือคั่นทุกส่วน |
| สีเดียวที่เด่นคือส้ม `#F9A03A` ใช้เฉพาะจุดกระทำ/สถานะหลัก | ปุ่ม gradient เงาเรืองแสงฟุ้ง วงแสงเบลอ หรือป้าย badge รก |
| ตลกหน้านิ่ง อบอุ่น ไม่กดดัน | เสียงโค้ชดุ "NO PAIN NO GAIN" หรืออีโมจิแทนไอคอน UI |
| ไอคอนเวกเตอร์เส้นสะอาดสม่ำเสมอ + แมววาดมือ 36 ท่า | ผสมหลายสไตล์จนดูไม่เป็นระบบ |

## 2. หลักการแยกชั้น (Operate-Mode Minimalism)

- **UI หายไปกับงาน:** ผู้ใช้ในยิมต้องแตะได้ทันทีโดยไม่ต้องเดาว่าอันไหนกดได้ อันไหนเป็นแค่ข้อความ
- **ไม่มีการ์ดซ้อนการ์ด:** ใช้การ์ดเฉพาะเมื่อต้องการแยกกลุ่มจริง ที่เหลือใช้พื้นที่ว่างและเส้นคั่นตรงบาง `1px` (`--line`)
- **ความโค้งมนชุดเดียวทั้งแอป:** ชิป/segmented `10px` · ปุ่มหลัก/ปุ่มรอง/ช่องกรอก `12px` · การ์ด `16px` · แผ่นล่าง (Sheet) `20px` · ปุ่มวงกลม (ติ๊ก ✓ / ปุ่มไอคอน) `9999px`

## 3. สี

ใช้ CSS variables ใน [globals.css](../../src/app/globals.css) ที่เดียว ห้ามใส่ `#hex` / `rgb()` / `hsl()` ตรงใน component · ทุกไอคอนใช้ `currentColor` · **โหมดมืดใช้ Neutral Graphite 4 ระดับ** (ยิ่งลอยสูงยิ่งสว่างขึ้น + ขอบบาง `1px`)

| Token | Light | Dark | ใช้กับ |
|---|---|---|---|
| `--paper` | `#FFFFFF` | `#0C0C0E` | พื้นหลังหน้าจอหลัก (Canvas) |
| `--paper-2` | `#F4F4F5` | `#17171A` | พื้นรองระดับ 1 (แถบ, ช่องกรอก, การ์ดรอง, ปุ่มรองในโหมดสว่าง) |
| `--surface-2` | `#EBEBED` | `#222227` | พื้นรองระดับ 2 (ปุ่มรอง Tonal / ชิป / ช่องกรอกในโหมดมืด) |
| `--surface-3` | `#FFFFFF` | `#2A2A30` | พื้นลอยระดับ 3 (Sheet, Modal, Toast, แถบสถานะโหลด) |
| `--ink` | `#111113` | `#F4F4F6` | หัวข้อ, ตัวเลขหลัก, ปุ่มหลัก, เส้นแมว |
| `--ink-2` | `#4A4A52` | `#C4C4CC` | เนื้อความหลัก |
| `--ink-3` | `#686870` | `#9898A3` | คำอธิบายรอง, placeholder, ป้ายรอง (ผ่าน ≥ 4.5:1 ทุกพื้นผิว) |
| `--line` | `rgb(17 17 19 / 0.09)` | `rgb(255 255 255 / 0.08)` | เส้นคั่นบาง 1px, ขอบการ์ด |
| `--line-strong` | `rgb(17 17 19 / 0.16)` | `rgb(255 255 255 / 0.16)` | ขอบปุ่ม/ช่องกรอกเมื่อโฟกัส, ขอบ Sheet |
| `--accent` | `#F9A03A` | `#F9A03A` | จุดเน้นเดียวของหน้า (PR, ปุ่มหลักตอนกด, เซ็ตที่ติ๊กแล้ว, ความคืบหน้า) |
| `--on-accent` | `#111113` | `#111113` | ตัวหนังสือ/เครื่องหมายบนพื้นส้ม (คอนทราสต์ ~9.1:1) |
| `--cat` | `#F9A03A` | ไม่ลงสี (`var(--paper)`) | ตัวแมว |
| `--cat-ear` | `#F4A19B` | ไม่ลงสี (`var(--paper)`) | หู จมูก |
| `--cat-white` | `#FFFFFF` | ไม่ลงสี (`var(--paper)`) | ท้อง ปาก |
| `--warn` | `#C0392B` | `#F27C72` | ลบ/ข้อผิดพลาดเท่านั้น |

กติกา
- **ส้มทำหน้าที่เดียวต่อจอ** (นอกจากตัวแมว) — จอที่ไม่มีบทบาทส้ม (หน้าหลักว่าง, ประวัติว่าง, ความคืบหน้าว่าง, ฉัน, ออกโค้ดเชิญ) ไม่มีสีส้มนอกตัวแมว
- ข้อความบนพื้นส้มใช้ `--on-accent` (`#111113`) ไม่ใช้ขาว
- ห้ามสื่อความหมายด้วยสีอย่างเดียว (PR = ส้ม + ดาว, แท็บที่เลือก = สีเข้ม + น้ำหนักหนา + แถบชี้/พื้นรอง, สถานะโค้ด = ไอคอน + คำ)
- โหมดมืดแมวยังคงเป็น **เส้นล้วน** (`--cat`/`--cat-ear`/`--cat-white` = `var(--paper)`) ตัดกับพื้น Graphite `#0C0C0E`

## 4. ตัวหนังสือ

**ฟอนต์หลักเดียวทั้งแอป: Noto Sans Thai** (self-host ผ่าน `next/font` เพื่อทำงานออฟไลน์ได้)

- น้ำหนัก: **400 เนื้อความ** (อ่านชัดในโหมดมืดกว่า 300 เดิม) · **500 ป้าย/ปุ่ม/แถวเมนู** · **600 หัวข้อหน้าและตัวเลขสำคัญ**
- ตัวเลขในหน้าจดและตัวนับ: `font-variant-numeric: tabular-nums` (`.num`)
- ภาษาไทย: `line-height ≥ 1.6` สำหรับเนื้อความ, `≥ 1.4` สำหรับหัวข้อ
- **คำเด่นลายมือ: Gaegu Light (300)** ผ่าน `<HandWord>` — ใช้กับคำสั้นภาษาอังกฤษเท่านั้น ขนาด ≥ 20px ตัวพิมพ์เล็ก · ห้ามใช้กับภาษาไทย ปุ่ม ช่องกรอก หรือข้อความสำคัญ (เป็นของตกแต่งคู่ข้อความไทยเสมอ)

ขนาด (มือถือ)

| ระดับ | ขนาด | น้ำหนัก |
|---|---|---|
| หัวข้อหน้า | 26–28px | 600 |
| หัวข้อส่วน | 18–20px | 600 |
| ตัวเลขใหญ่ (น้ำหนัก×ครั้ง, timer) | 28–44px | 600 |
| เนื้อความ | 16px | 400 |
| คำอธิบายรอง / ป้ายแท็บ | 14px | 400/500 |

ขั้นต่ำ 14px ทุกข้อความที่มองเห็น · ช่องกรอกทุกช่อง ≥ 16px (กัน iOS ซูมเอง)

## 5. ตัวละครแมว (คงต้นฉบับเดิม 36 ท่า)

**แมวส้มอ้วน หน้านิ่ง ตัวเป็นก้อน** — ต้นฉบับอยู่ที่ `docs/design/samples.html` ที่เดียว ส่งออกด้วย `node scripts/export-stickers.mjs` เป็น SVG inline `<Cat pose="..." motion />` ใน `src/components/doodle/**`

- บุคลิก: ขี้เกียจแต่มา · ภูมิใจกับความสำเร็จเล็กๆ เกินเหตุ · ไม่เคยดุผู้ใช้ · ไม่พูดเรื่องรูปร่างในเชิงลบ
- **แมวไม่ผอมลงตามน้ำหนักผู้ใช้** — เปลี่ยนเฉพาะท่าทางและอารมณ์ (36 ท่าตามตารางเดิมใน `docs/design/samples.html`)

## 6. องค์ประกอบหน้าจอ (Studio Minimal)

| องค์ประกอบ | รูปแบบ |
|---|---|
| ปุ่มหลัก (`Button`) | พื้นทึบ `bg-ink text-paper` มุมโค้ง `12px` สูง ≥ 52px (`min-h-13`) · กดแล้ว `scale(0.985)` + พื้นส้มชั่วขณะ · ปุ่มลบ/อันตรายใช้กรอบและตัวหนังสือ `--warn` บนพื้น `--paper` · ระหว่างโหลดแสดง **จุดเด้ง 3 จุด** (`<LoadingDots />`) ข้างข้อความ |
| ปุ่มรอง (`TextButton`) | ปุ่มพื้นรอง Tonal (`bg-paper-2` / `bg-surface-2`) มุมโค้ง `12px` สูง ≥ 44px — **ไม่มีเส้นยึกยือ** |
| ปุ่ม ✓ ติ๊กเซ็ต (`TickButton`) | วงกลมสะอาด ≥ 56px (`size-14`) ขอบ `2px` · ติ๊กแล้ว = พื้นส้ม `--accent` + เครื่องหมายถูก `--on-accent` |
| แผ่นล่าง (`Sheet`) | พื้น `--surface-3` มุมโค้ง `20px` ขอบบาง `1px` `--line-strong` + มือจับลากลงสะอาด |
| ช่องกรอก (`TextField`, `NumberInput`) | กล่องสะอาดพื้นรองมุมโค้ง `12px` ขอบ `1px` เปลี่ยนชัดเมื่อโฟกัสหรือ error (`--warn`) · ปุ่ม −/+ วงกลมสะอาด 48px |
| ชิป (`Chip`) / ตัวเลือก (`ChoiceGroup`) | สี่เหลี่ยมมุมโค้ง `10px` สูง ≥ 44px · เลือกอยู่ = พื้น `bg-ink text-paper` · ไม่ได้เลือก = พื้นรองขอบบาง `1px` |
| เส้นคั่น (`Divider` / `Squiggle`) | เส้นตรงบาง `1px` สี `--line` — **ไม่มีเส้นหยักหนา** |
| แถบนำทางล่าง (`BottomTabs`) | พื้นทึบ `--paper` + เส้นขอบบนบาง `1px` `--line` · แท็บที่เลือก = พื้นรองแคปซูล + ไอคอน/ตัวอักษร `text-ink` หนา + แถบชี้ด้านล่าง (ไม่พึ่งสีอย่างเดียว ไม่มีเส้นหยัก) · แสดงแถบลอย **จุดเด้ง 3 จุด** เมื่อเปลี่ยนหน้าช้า (ผ่าน `useLinkStatus` ไม่ใช้ `loading.tsx`) |
| Empty state / Status screen | ภาพแมว `<Cat>` + ประโยคสั้น + ปุ่มเดียว |
| แจ้งเตือน / Toast | แถบลอยพื้น `--surface-3` มุมโค้ง `12px` ขอบบาง `1px` + เงาอ่อน |

เลย์เอาต์
- mobile-first กว้างสูงสุดของเนื้อหา 480px (`max-w-120`) จัดกลาง · ขอบซ้ายขวา 20px (`px-5`)
- ระยะห่างฐาน 4px: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 · แยกกลุ่มด้วยที่ว่างและเส้นคั่นบาง `1px`
- หน้าจด `/log` เน้นความแน่นพอดีและรวดเร็ว ไม่มีกล่องซ้อนกล่อง

## 7. การเคลื่อนไหว

- สั้นและมีเหตุผล (150–220ms) — แสดงสถานะและตอบสนองการกด ไม่หน่วงการทำงาน
- **จุดเด้ง 3 จุด (`<LoadingDots />`):** Pure CSS `@keyframes` เด้งไล่จังหวะ 0.85s (หน่วง 0 / 110 / 220ms) ใช้ใน `<Button loading>` และตัวบอกสถานะเปลี่ยนหน้า (`useLinkStatus`) — ไม่มี SVG id ชนกัน
- **แมวขยับ 5 เฟรม:** คงระบบเดิมใน `<Cat pose="..." motion />` (CSS sprite strip 0.7s steps(5)) ใช้เฉพาะตัวแมว ไม่ใช้กับปุ่มกด
- **เคารพ `prefers-reduced-motion: reduce` ทุกชิ้น** — ปิดแอนิเมชันทั้งหมด เหลือเฉพาะการเปลี่ยนสถานะทันที

## 8. น้ำเสียงข้อความ

- สั้น เป็นกันเอง พูดแบบเพื่อน ไม่ใช่โค้ช · ชมการ "มา" มากกว่าตัวเลข · ไม่ตำหนิ ไม่ตัดสินน้ำหนัก

## 9. การเข้าถึง (ผูกกับเกต A11y ใน PROCESS.md)

- คอนทราสต์ข้อความ ≥ 4.5:1 ทั้งสองโหมดบนทุกชั้นพื้นผิว
- พื้นที่แตะ ≥ 44×44px ทุกปุ่มและลิงก์ · ปุ่มหลัก ≥ 48px · ปุ่ม ✓ ≥ 56px
- ภาพแมวตกแต่งใส่ `aria-hidden` · ภาพสื่อความหมายมี `alt`/`aria-label`
- กรอบ focus ชัดเจน 2 ชั้น (`box-shadow` ขอบพื้น + ขอบ `--ink`) ไม่ลบ `outline` ทิ้ง
- Browser chrome (text selection, caret, scrollbars) ปรับให้เข้าชุดกับ token ของแอป

## 10. แนวทางทำจริง

- ตั้ง token สีและระยะห่างทั้งหมดใน `src/app/globals.css` ห้ามใส่ค่าสีตรงใน component (`src/app/tokens.test.ts` ตรวจอัตโนมัติ)
- ภาพแมวยังคงเป็น SVG inline ใน `src/components/doodle/**`
- คง utility alias (`border-draw`, `rounded-hand`, `underline-hand`) ใน `globals.css` ให้แมปเป็นสไตล์ Studio Minimal สะอาดเพื่อความเข้ากันได้กับโค้ดในสาขาที่พัฒนาขนานกัน (`r3a-logging`)
