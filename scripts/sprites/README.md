# แมวขยับจริง — sprite 5 เฟรม (`scripts/sprites/` → `assets/stickers/motion/`)

ชุดนี้ทำแทน sprite ดุ๊กดิ๊ก 3 เฟรมเดิม (`assets/stickers/sprites/`) ด้วย **5 เฟรมที่เปลี่ยนท่าจริง** —
เดินเห็นก้าวขาสลับ, สควอทเห็นตัวยุบ, ยกดัมเบลล์เห็นแขนงอและดัมเบลล์ขยับตามมือ

ภาพต้นฉบับคือ `assets/stickers/svg/<ชุดสี>/NN-name.svg` (ซึ่งมาจาก `docs/design/samples.html` อีกที) (ตัวเดียวกับที่ใช้ทำ `png/` 512×512)
ไม่ได้วาดใหม่ทั้ง 36×5 เฟรม แต่สร้าง **rig 2 มิติแบบ cutout** ขึ้นมาแล้วจัดท่าใหม่ทีละเฟรม

## ไฟล์ในโฟลเดอร์

| ไฟล์ | คืออะไร |
|---|---|
| `build.mjs` | ตัวสร้างแผ่น sprite (อ่าน SVG → จัดท่า 5 เฟรม → เรนเดอร์ → ครอป) |
| `rigs.mjs` | config การขยับของทั้ง 36 ตัว (แก้ท่าที่นี่) |
| `demo.mjs` | สร้าง `demo.html` จากแผ่น PNG ที่มีอยู่ |
| `assets/stickers/motion/demo.html` | หน้าเปิดดูทุกตัวขยับ + สลับชุดสี + ดูเฟรมทีละเฟรม |
| `assets/stickers/motion/svg/<ชุดสี>/` | แผ่นเวกเตอร์ 5 เฟรม (ไว้ debug / เปิดดูในเบราว์เซอร์ได้) |
| `assets/stickers/motion/png/<ชุดสี>/` | แผ่น PNG ที่ใช้จริง 36 ไฟล์ต่อชุดสี |
| `assets/stickers/motion/.tmp/` | cache ตอนเรนเดอร์ ลบได้ทุกเมื่อ (สร้างใหม่เอง) |

โฟลเดอร์ `assets/stickers/motion/` ทั้งหมดสร้างใหม่ได้ จึงไม่ขึ้น git (มีแต่สคริปต์ในโฟลเดอร์นี้) · ถ้าแก้ภาพต้นฉบับใน `samples.html` ให้รัน `node scripts/export-stickers.mjs --no-png` ก่อน แล้วค่อย build sprite ใหม่ — rig อ้างอิง element ตามลำดับวาดใน SVG ถ้าเพิ่ม/ลบชิ้นส่วนต้องไล่ index ใน `rigs.mjs` ใหม่

## รูปแบบแผ่นภาพ

- แผ่นละ **2560×512** = 5 เฟรม × 512 px เรียงแนวนอน (ของเดิม 1536×512 = 3 เฟรม)
- พื้นโปร่งใส, เฟรมละ 512×512, ยึดกริดเดิมของภาพนิ่ง (เซลล์ 232 หน่วยศิลปะ, สเกล 512/232 ≈ 2.2069)
- ทั้ง 3 ชุดสี (`color`, `line`, `line-white`) มี geometry และจังหวะตรงกันทุกเฟรม สลับชุดสีได้โดยภาพไม่กระโดด
- ลำดับเฟรมเป็น loop: เฟรม 4 กลับไปเฟรม 0 ได้เนียน (ทุก rig ตั้งค่าให้ค่าเริ่มต้น = ค่าสุดท้าย)

## วิธีรัน

```bash
node scripts/sprites/build.mjs              # สร้างทั้ง 36 ตัว × 3 ชุดสี (~1 นาที)
node scripts/sprites/build.mjs 02-side      # เฉพาะตัวเดียว
node scripts/sprites/build.mjs 05-squat,26-pull-up   # หลายตัว คั่นด้วย comma
node scripts/sprites/demo.mjs               # สร้าง demo.html ใหม่หลังแก้ไข
```

ต้องมี Chrome หรือ Edge (สคริปต์หาเองจาก path มาตรฐานของ Windows หรือใส่ `CHROME=...`) · ขั้นครอปแผ่นใช้ PowerShell จึงรันได้บน Windows เท่านั้นตอนนี้

## วิธีแก้ท่า

แก้ `scripts/sprites/rigs.mjs` แล้วรัน build ใหม่ — 1 rig มี 3 ก้อน

```js
"05-squat": {
  body: { pivot: [100, 196], dy: [0,1,2,2,1], sy: [1,0.97,0.915,0.915,0.97] },
  limbs: [{ el: [4,5], type: "rot", angles: [0,2,4,4,2] }],
  parts: [{ el: [13,14], pivot: [172,80], rotate: [0,-12,-24,-12,0], follow: 1 }],
}
```

- `body` — ขยับทั้งตัวรอบ `pivot` (หน่วยศิลปะ): `dx` `dy` `rot` (องศา, ทวนเข็ม+) `sx` `sy`
- `limbs` — ขา/แขน/หาง เป็นคู่เส้น (เส้นขอบเข้ม + เส้นสีตัว) ระบุ index ตามลำดับ element ใน SVG
  - `type: "rot"` แกว่งแข็งรอบโคนแขน/ขา → เหมาะกับขาที่ตรง
  - `type: "ik"` ล็อกปลายไว้กับที่แล้วดึงโคน → เหมาะกับแขนที่ต้องเกาะบาร์/พื้น (`bend` = ความโค้ง, `bendSign` = บังคับทางโค้ง, `targets` = เลื่อนปลายเอง)
- `parts` — ของประกอบ (ดัมเบลล์ ถ้วย ปลา ฯลฯ): `translate` `rotate` `scale`/`sx`/`sy` `opacity`
  และ `follow` = ตามมือของ limb นั้น (ใส่ array ได้ = เกาะสองมือ แล้วเฉลี่ย)
- `statics` — element ที่ต้องตรึงไว้กับที่ (พื้น บาร์ จักรยาน) ไม่ขยับตามตัว
- ทุกค่าที่เป็น array ต้องมี 5 ตัว (หรือใส่ค่าเดียวเพื่อใช้ทุกเฟรม)
- ตัวช่วยสร้างคลื่น: `S(amp, phase)` เริ่มที่ 0, `C(amp, phase)` เริ่มที่ amp

index ของ element ดูได้จากลำดับ drawing ในไฟล์ `svg/color/NN-name.svg`
(นับทั้ง path, circle, ellipse ตามลำดับที่วาด ไม่นับ `<defs>`)

## หมายเหตุของ engine

- อ่าน SVG ด้วย parser เล็กๆ ใน `build.mjs` — เก็บ `<defs>` (wobble filter) ไว้ แล้วเติม prefix
  `f0-` `f1-` … ต่อเฟรม เพราะแต่ละเฟรมเป็น `<svg>` ซ้อนกันในแผ่นเดียว
- แขน/ขา/หางจับคู่จาก path ที่มี `d` เดียวกัน (เส้นหนา 17 + เส้นสีตัว 8)
- `rot` หมุนรอบจุดเริ่มของ path ในพิกัดของ parent; `ik` เขียน geometry ใหม่เป็นพิกัดจริงของภาพ
  ทำให้ปลายที่ล็อกอยู่กับที่ (พื้น/บาร์) ไม่เลื่อนหนีตอนตัวขยับ
- ข้อจำกัด: IK ยืดแขนไม่ได้ — ถ้าตัวขยับหนีปลายมากเกินไป แขนจะตึงเป็นเส้นตรง
  ตัวที่เจอปัญหานี้ (เช่น `17-stretch`) จึงใช้ `rot` แทน
